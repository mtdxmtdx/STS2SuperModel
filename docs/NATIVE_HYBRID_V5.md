# Public-history sampler v5

The sampler implementation is
`nosl-native-rewards-state-tape-conditional-v5-public-evidence-v1`.
The hypothetical Rewards-hybrid prior remains
`nosl.native-rewards-state-tape-prior.v1`; the default observation channel, native
source packets and old corpus are unchanged. This iteration addresses rejection
causes measured in the repeated v4 diagnostic. All emitted rows remain quarantined
engineering records. It does not admit production data or authorize new fitting.

## Composed constraints

The public first-cycle certificate can extend each initial shuffle's observed
card prefix through later turns and reviewed actions. It stops before an
unproved action, generated card, evidence gap, or first reshuffle. Every crossed
native action and active listener must have a source-pinned closure; a quiet
recorded history alone is insufficient because it does not report arbitrary
pile moves. The existing physical-card permutation proposal and exact correction
remain unchanged. Per-combat diagnostics record the certificate version, initial
and extended draw counts, last certified event, and stop reason. LavaRock's
reward-only hook and Sharp's damage-only effect have explicit startup support.
See [the first-cycle proof](NATIVE_PUBLIC_FIRST_DRAW_CYCLE.md).

The first published CorpseSlug intents fix its native cyclic starter bucket.
A separate owned factory scope proposes the complete preimage of the original
single NextInt(3) call. Its exact floating-point bucket mass is also the
root-constant envelope. The normal and weak factories retain their native
transitions; parented/prepared event contexts fall back to ordinary replay.
The owning tape forwards all combat indices, retains the condition and forced
cells in ReplayCopy, and validates completion before any correction rejection.
See [the native boundary and finite law](NATIVE_CORPSE_SLUG_INITIAL_INTENTS.md).

The initial map component now reuses the independently certified opening-roster
act. Wrong-act candidates stop before map generation. Each trial still redraws
the entire seed and independent native prefix; the selected trace contains the
actual unmodified act/map calls. The joint event has a root-constant normalizer,
and unavailable roster evidence leaves both acts possible. A fixed 64-candidate
component diagnostic avoided 36 wrong-act map constructions and reduced native
callback words from 17,824 to 7,938. That is a component-work observation, not a
full-posterior throughput result. See [the joint predicate](JOINT_PUBLIC_ACT_MAP_PREFIX.md).

## An unsuccessful optimization hypothesis

An optional, separately declared coordinate-ordered map observation profile
forgets incidental native option enumeration while retaining coordinates,
visible nodes, edges and selected destinations. It preserves native actions and
random state, and old packets/prior identities remain unchanged unless the new
profile is explicitly selected. The paired 512-prefix diagnostic found exactly
the same acceptance on both measured roots under both channels: 7/512 and 3/512.
There is no measured throughput benefit. The v5 default and its repeated
full-history comparison therefore retain the original raw observation channel.
See [the profile and negative result](PUBLIC_MAP_OBSERVATION_PROFILE.md).

## Verification and comparison discipline

The owning-tape tests combine public card grants, extended draws and slug intents
and compare complete public packets and continuation forks through terminal
settlement. They deliberately reuse fixed native recipes to isolate integration;
they are not independent posterior acceptance evidence. Helper finite-word tests,
legacy identity checks and independent composition review remain separate evidence.

The completed bounded comparison used the same eight already inspected source roots,
two evaluation seeds, 64 outer attempts per world, 64 complete prefix trials,
200 continuation decisions and 360-second total budget as v4. Failed proposals,
unknown mass, cancellation and unexecuted roots must all remain in the output.
This comparison cannot establish fresh breadth or an unbiased population of roots
selected by completion before a clock deadline. Any production-scale admission
requires a further predeclared fresh development cohort and the existing data
quality gates. The frozen test split and experimental weights remain untouched.

The run finished all eight sources in 336.07 seconds without the clock cutoff.
It accepted 9 worlds and settled 59 of 96 allocated candidate-world copies;
37 remain ComputeTruncated, with zero engine errors. Four roots completed fully,
one partially and three had no accepted world. All source public packets and
the prior identity match the original cohort. Two of the six predeclared
multi-action roots completed fully, and neither combat-index-two root completed,
so the gate failed. V4 had accepted 2 worlds and settled 16 copies before its
clock limit, leaving four sources unexecuted. Its initial timing overlapped a
test run; this v5 run was isolated, so it is not a controlled CPU speed ratio.

The complete v5 attempts include 225 prefix budget exhaustions, 252 public
mismatches, 7 density correction rejections and 9 accepted worlds. Specific
remaining mismatches identify native reshuffle draws, weighted monster intents
and weak-slime formation draws. Those are the next bounded implementation targets.
See [the exact result and hashes](../configs/native_rewards_hybrid_v5_verification.json).
