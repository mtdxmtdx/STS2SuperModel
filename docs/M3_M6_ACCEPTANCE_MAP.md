## Engineering work still open

The other 184 remain raw. Reflex/Tactician v3 is a constructed-family extension, with separate prior/version and exclusions. It is not a general natural-state solution

3. **Broader loops and stalling.** Finite attack cycles and the narrow v2 defense/draw exit have real evidence. General beneficial stalling, semantic loop/progress detection, and any accelerated macro with expansion/RNG/side-effect/exit equivalence remain open. Atomic replay is not a macro test
4. **Active bonus control.** The finite TheHunt evaluator carries public memory and fixed deadlines, but ordinary teacher records and student schema admit only inactive controller context. Active memory, supervision, encoding and inference transitions need engineering; a preference answer cannot supply them
5. **Resource provenance and useful supervision.** General permanent/resource-event provenance and resource-aware targets remain incomplete. The separate common-inventory relative API identifies only guarded paired differences; it does not assign prices or fill ordinary absolute labels
6. **Instrumentation and evaluation.** The balanced block has no root satisfying the narrow v2 cycle certificate; continuation-wide activation was not instrumented, so no completion improvement is attributed to that fix. Broader source/phase coverage, targeted posterior runtime evidence and statistical reporting remain open. Final export parity is later M8 delivery work
