## 1. 需求冻结

### 1.1 必须保持的行为

- 只作战斗内决策；教师评估至战斗与必须发生的自动结算完成、下一次战后真实玩家选择之前。
- 不追求速通；明显死亡风险优先处理，其次整场预期血量代价及严重坏结果。不存在“当前回合占 90%”。
- 正常情况下，药水整场边际保血达到 9 点可考虑使用，而不是必须现在喝；救命可低于此门槛。9 不是所有药水的永久固定报价。
- 为指定斩杀等额外收益，相对于正常基准打法，允许整场额外**期望**战损至多 5 点；下一玩家回合结束前指定斩杀并实际获得收益的成功概率达到 80% 可接受。仍须比较其他方案并满足安全约束。
- 可安全、有限地延长战斗获取真实收益；此类安全拖回合不强行套用指定斩杀的下一回合窗口。
- 在当前 60 血、都能获胜、资源相同的示例中，90% 无伤＋10% 掉 30 优于固定掉 8。平均同为 3 时，固定掉 3 优于该波动方案。
- 合法且能结束战斗的无限允许，动作次数多不等于低分。起防达到所需效果后，停止无益循环，继续有益动作再结束。
- 训练与部署的每一次玩家选择都受同一公共信息边界约束；合法记牌、已知牌顶和公开规则推导不是作弊。

### 1.2 首版范围，不等于第一轮调试范围

首版目标是 Silent 单人 A10 合法进入战斗并影响战斗的卡牌、升级、敌人、遗物、药水及相关状态、附魔、生成与跨池效果。不是仅支持初始牌组，也不是要求完整支持其他角色。

用内容注册表和可达性证据产生 `coverage_manifest`：内容 ID、版本、来源、生成依赖、所需机制、状态、测试和原版证据。状态为 NotAudited / ImplementedUnverified / Verified / Partial / Blocked / OutOfScope。只靠登记某张牌名称不能宣布全部组合已验证；明确列出交互覆盖限度。

少量局面的闭环称 `PILOT_READY`，不叫“首版完成”。全量目标有缺口则准确报阻塞，不静默删动作、禁卡或改成 A0 后宣称完成。需要修复的模拟器机制可以在原规则实现中作最小改动，不在 Python 另写规则副本。

### 1.3 最终交付边界

独立模型权重＋公共输入契约＋编码解码＋必要确定性前处理＋运行示例＋评估报告。部署不要求 simulator、真实 seed、搜索树、教师评分或游戏模组。公共输入来自外部调用方；模型不负责监听游戏或自动出牌。断言“置信度”前必须定义并校准它。

## 2. 本次核对的源码基线

仓库：`mtdxmtdx/sts2-sim`；main 核对到 `a3a66276ee79bf9f75e8af32e9ef5a51592b26f8`。README 声明基线 STS2 v0.111.0、release commit `41cef1ea`、assembly hash `222455745`，核心为 C#/.NET 9。此为**模拟器的声明基线**，不等于用户客户端或当前游戏最新版。[R1–R2]

| 已核对事实 | 直接工程含义 |
|---|---|
| CombatState.Clone 精确保留 RNG，且没有战斗级 CloneReseeded | 克隆 100 次不是抽取 100 个未知未来；必须新增公开信念条件采样适配。 |
| CombatStateDescription 声明不是玩家可见序列化契约，并含 seed/RNG | 可用于隔离的精确回放审计，不可直接成为 NN 输入或策略节点 key。 |
| CombatRoom.ResolveVictoryOnceAsync 调用战斗完成与胜利 hooks | Engine.Won 不是终局血量的完整结算边界。 |
| 战斗克隆的 run facade 与 room 生命周期并非整局深克隆 | 不能对 clone 调用原 room 的结算函数，污染活局或重复触发回血。 |
| README 明确 keyed label RNG 有意不同于游戏顺序 RNG | 首版保真/评测只用顺序模式；keyed 不作为默认 NOSL 正确性保证。 |
| README 列出未实现／部分实现内容 | 先记录缺口和影响，不能把“全部移植”当成全部验证。 |

源码只作了与本方案有关的定点检查，未宣称全仓代码审计或构建成功。[R3–R7]

## 3. 架构与职责

```text
固定版本 sts2-sim
   │ 执行全部游戏规则、合法性、随机事件、自动结算
   ├── SimulatorWorker（私有完整状态；不外发隐藏状态）
   ├── PublicObservationBuilder + PublicHistoryTracker
   ├── BeliefSampler（公共信息条件分布，不读取实际未知未来）
   └── TerminalSettler（与 live 相同规则、branch 自己的生命周期）
                    ↓
       Public-information Teacher（离线）
     动作候选 → 受限续策/搜索 → 完整终局样本
                    ↓
     Outcome dataset + Objective evaluator + Pair labels
                    ↓
     Python trainer → 独立 action scorer（student）
                    ↓
        纯公共输入的学生闭环评测与原版对拍
```

建议 C# 保留模拟、分支执行和初始规则续策；Python 负责训练及报告，避免每个内部自动效果都跨语言 RPC。开始可用长驻 worker＋JSONL 批量任务；只有实测序列化成为瓶颈才换协议。不要为选型提前建设分布式集群。

`Observe`、`EnumerateActions`、`Step`、`SampleWorld`、`Settle` 是拟新增适配层概念，不是假称仓库已有同名 API。

## 4. 分阶段里程碑

### M0：版本、内容与运行环境审计

输入：本包、指定 checkout、可用运行环境。先读仓库 AGENTS/README 与现有代码，建立实现证据矩阵，不无关升级依赖。

工作：锁模拟器 commit、游戏规则版本、SDK；核对目标内容；运行实际 build/test 并记录命令与退出码；采集 CPU/内存/磁盘/GPU 信息；列出全量支持缺口。用户实际游戏版本不明时记录 `client_version_unverified`，不伪称匹配。

交付：`baseline.lock.json`、`coverage_manifest.json`、`implementation_audit.md`、`environment_report.json`。

通过条件：基线可复现；构建状态真实；哪些内容可测、缺哪些来源清晰。不把 README 提及私有工具理解成公共仓库可直接使用。

### M1：单场战斗适配和真实终局边界

从 Silent A10 的受限测试局面起步，只为测试技术闭环，不改变首版范围。

工作：初始化；获得合法动作；执行出牌、目标、药水、结束回合和必要子选择；记录每个真实决策边界；自动运行非玩家阶段；结算胜负及必要 hooks；只在正确边界抽样。

出牌需核对对象属于当前状态；clone 使用 CombatCloneMap 或重新解析公共 action token。禁止拿活局 Card/Creature 引用在分支中执行。合法性不能只做“费用<=能量”，也不能用试执行后的好坏过滤候选。

对子选择，安装显式 decision source；异步等待不能当作可随意复制的协程栈。优先在稳定边界克隆；复杂中途选择用独立 worker/replay 进入同一个 choice，或在引擎中新增经过验证的 continuation adapter，不重写牌效果。

**终局专项**：复用原生命周期规则，为投影建立独立结算上下文/最小公共 resolver。原 room 引用、pending rewards、hooks、玩家引用和一次性任务均不能共享可变状态。不能未经验证就把 `generateRewards:false` 当成完整结算捷径；若生成奖励前的自动 hooks 会改变血量/状态，仍须执行到声明边界。奖励选项本身不进入战斗外决策价值，已约定的额外收益另记。

在清理战斗对象前采集必要的伤害/出牌/资源事件事实，最终HP在全部自动结算后读取，避免清理后丢统计或清理前漏回血。审计 IsProjection 分支及全局/缓存可变对象：不能默认同进程并发安全；先用隔离worker，证明隔离后才增大并行度。

交付：环境适配、终局测试、克隆污染测试、动作/choice 一致性测试。

通过条件：起步场景中每条合法动作可执行，非法动作显式拒绝；clone 不污染原状态；原始驱动与分支结算在相关公开结果上相同；异常与真实失败分别记录。

### M2：公共观测、知识状态与未知世界采样

工作：显式字段白名单；手牌顺序与公开槽位保留；未知抽牌堆只编码公开可知多重集合及位置约束；公开计数和已知牌顶随事件更新；隐藏状态、对象指纹、内部 move state 不直接外发。

BeliefSampler 应满足 `P(hidden | public history, known constraints)`。先验证有限支持机制，再扩展；不是对整副牌随意 shuffle，也不是仅 reseed 而保留已物化的真实抽牌序列。已公开当前意图不能重新抽样；未知 monster memory 按公开历史的后验处理，非未知字段不能乱改。

未来随机状态与采样 seed 来自独立 sampler。分支先采样一个假想世界，再对不同候选复制这个世界。后续决策只见各自的新公开信息。共同随机数仅用于减小比较噪声，须保留每条路线正确的边际分布；不能把两个不同动作强行变成相同随机事件。

交付：PublicObservation schema、knowledge updater、belief sampler、隐藏替换/公开约束/策略融合测试。

通过条件：同公共历史换真实隐藏序列，固定 sampler 配置后的输入、候选、教师分数一致（数值容差）；抽到牌以后可以分化；小可枚举场景采样分布与精确值对上。策略进程不可读取审计状态。

### M3：偏好契约和终局评价校准

直接采用 `TEACHER_CONTRACT_V4.md` 的结果向量、期望终局代价以及 9/5/0.8 规则。先运行本包 30 个合成检查，再把其对应情况接到真实模拟器；合成测试通过不替代集成。

新风险系数是候选实现值而非用户原话。固定对照案例、做敏感性分析；风险评价采用固定终局效用的条件期望，尾部统计先作为诊断，不逐步重新截取“最差10%”并当成相同目标。

永久收益和药水例外的血量等价值不是已确认常数，必须用版本化表和证据登记。不为了尽快打分把未知价值默认为0。微小死亡概率与资源取舍不能声称已被一个偏好例子唯一决定。

通过条件：已确认偏好不被公式反转；9点只判“值得考虑”；5点不每回合重开；80%边界与采样不确定性分开；结算与资源无双重计算。校准报告决定哪些目标档案可生成正式标签。

### M4：完整战斗教师，从可审计到更强

T0：对每个合法根动作，从同一公共信念分布采样；执行根动作；由冻结的 NOSL 规则策略继续至终局。这是 `Q^pi`，不是最优价值。规则策略优先复用被审计过的公开信息逻辑，不复制模拟器伤害规则。

T1：加入公开信息树搜索；节点按公开历史/知识/控制器记忆区分，不按完整隐藏 state 区分。可采用 POMCP 风格结构，按观察分支；并不要求部署在线搜索。[R8]

T2：在学生已经训练并独立评估之后，学生引导教师搜索/续策；每版都记录 continuation policy ID。算法名称不等于NOSL证明，也不保证单调提升。[R9]

探索样本可从每动作32个开始，自适应增加到128、512等；这些是可改的工程起点，不是统计精度证明。冻结本批续策后，用**独立最终评估样本**计算标签，避免复用挑赢家的搜索结果。近似等价的动作可保留集合。超大动作集只能报告部分覆盖，不能称“全动作最优”。

探索树可以有限深，但叶子默认用 NOSL 续策跑到实际终局；预算耗尽记 `COMPUTE_TRUNCATED`。未决长战斗不能被删除后重新归一化成乐观标签。精确检测到无收益且无退出的重复策略可记 `POLICY_NONTERMINATING`，仍与真实游戏失败分开。

合法循环：只在证明循环的语义状态、资源变化与退出条件后作 macro 加速；公开状态看起来重复不等于隐藏过程没有进展。宏动作须可展开成真实原子动作并做等价测试；不直接修改 HP/能量来“跳过规则”。

通过条件：完整结果质量与计算成本清楚；T1在精确小题中不策略融合；续策也过隐藏替换测试；T0标签不冒称搜索最优；teacher版本和终点可追溯。

### M5：覆盖扩展与训练数据生产准备

按内容依赖扩展到首版目标：直接攻防→抽牌/弃牌/消耗/保留与选择→持续状态与触发→药水/遗物交互→额外收益与合法循环→精英/Boss/强制遭遇及特殊机制。顺序是验证顺序，不是降低验收范围。

数据既来自合法自然到达的战斗，也来自声明过的构造场景与压力测试。允许从模拟器用固定外场脚本生成牌组与战斗，但模型不学习地图/奖励动作。登记来源分布，避免把不可能局面混成自然分布。

按原始run seed、源战斗、分支族及重复公共局面进行隔离；不按动作行随机切分。训练/验证/测试可从80/10/10分组起步，真正比例由覆盖和独立样本量决定。另留组合泛化集及低血量等困难集。

首个吞吐实验建议200个公开决策点，每点保存全部合法候选；报告每动作终局样本成本、有效样本率、克隆和结算耗时、每worker内存。之后再推导5,000级或更大试验，不能预先承诺百万数据的时间。

粗略计算预算：`root数 × 平均动作数 × 每动作独立world数 × 平均续策决策数`，另计搜索展开和最终独立评估；不要把一次长rollout里的多个节点当成独立world。

通过条件：支持矩阵与标签质量一致；train/test相关性检查通过；错误不混入loss；缺失全量内容则只报告 `PILOT_DATA_READY`，正式全范围准备标记仍为Blocked。

### M6：学生结构与训练工程，终点 READY_FOR_TRAINING

输入：公共数值、可见卡牌/状态实体、无序未知抽牌多重集合、已知位置、必要公开历史摘要、当前候选动作、合法mask、公开控制器记忆。初始化HP等固定参照必须可由接口提供，不能部署缺字段。

结构起点：共享实体embedding＋轻量集合/注意力编码＋候选动作条件MLP；可先试128维表示、2层编码器，参数规模以实际统计为准。未知牌堆不加隐序位置编码；手牌和有意义的公开顺序不能为了方便全池化。不要先训练大模型。

头：排序分；胜负/死亡概率；预期终局血量或净战损；血量分布/分位；药水净变化；指定额外收益成功与增量代价（有对应标签才开启）；适用性状态。`policy_id`、搜索预算、teacher confidence、真实seed只在训练审计侧，不能作为需要部署提供的特征。

损失：相对动作排序＋终局结果回归＋概率校准；多个有效动作使用soft/集合标签。不确定性用于样本权重/排序mask，不把教师猜测当一条绝对真理。风险分位与均值可以多头，但避免用相互不一致的头偷偷重算另一套政策。

交付训练程序、数据loader、schema检查、单批前向/反向单测、独立推理代码、固定实验配置。尚不启动真实正式训练、不晋升权重。公共前处理可更新知识与自身记忆，但不能展开搜索或调用教师。

READY_FOR_TRAINING 不等于模型完成。若硬件、规则版本、全范围覆盖或目标校准仍有阻塞，状态必须准确细分；允许先READY_FOR_PILOT，但不得同名混用。

### M7：正式试训与学生闭环改进（单独执行阶段）

正式启动需明确实际资源与执行范围。先进行小规模试训，验证能学过拟合的少量干净标签，再做分布外/独立种子检查；从规则基线、纯学生、教师分别测量。

之后收集学生自己会遇到的局面，教师重评并加入训练集，测试集保持封闭。这是借鉴数据聚合和 Expert Iteration 的工程路线，不宣称与论文算法完全相同或效果保证。[R9–R10]

学生风险头训练于哪种续策就标明哪种续策；教师下预测的胜率不能直接冒充纯学生实战胜率。重新用纯学生闭环结果校准，任何新一轮都可以退步，不自动晋升。

### M8：独立验收、原版对拍与交付

评测使用未训练的分组seed、顺序RNG、纯学生推理；相同初始公开/真实环境条件作配对比较，但双方策略都看不到私有状态。置信区间按独立源战斗/run聚合，不能把分支当独立局。

主报告：胜率/死亡、净战损、终局血量、坏结果分布、药水/永久收益、未决与工程错误率；速度最后。区分全部结果、双方都赢、各自获胜条件下统计，不能用只看胜者的平均血量掩盖更多死亡。准确报告低概率事件的统计不确定性。[R11]

原版对拍：公开起始场景和动作trace，对比伤害、抽牌/洗牌、intent、选择、触发序、最后结算；保真调试可读真实seed但在隔离工具链，绝不能回流策略输入。差异关联内容/机制/标签分片，修复后重生成受影响数据。

学生最终包在无模拟器、无教师、无真实seed环境运行；同公共输入得到稳定输出；输入无效、未知机制、历史不足可明确拒答/降可靠性，不自动触发在线搜索。导出格式与原框架输出一致性需要实测，不只写“已导出”。

全范围首版完成条件：范围内缺口已处理且证据可追踪；偏好回归通过；NOSL自动化边界通过；纯学生闭环达成预先冻结的胜率非劣及保血改善标准；原版对拍无未处理关键偏差。有限测试不等于全游戏数学正确证明。
