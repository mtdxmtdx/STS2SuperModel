# 给编码 agent 的执行指令：NOSL V4 训练准备

## 任务与当前授权

读取本包 README、PLAN_NOSL_FULL_COMBAT_V4.md、TEACHER_CONTRACT_V4.md、配置及验收目录。目标是复用 `mtdxmtdx/sts2-sim`，完成独立 Silent A10 单人战斗 NOSL 模型所需前置工程，默认终点 `READY_FOR_TRAINING`，不是立即正式训练或发布。

最终产品是独立动作评分网络，不是游戏模组、自动出牌器或在线搜索工具。先调查现有实现并复用；旧方案的当前回合短视界、多目标默认不能覆盖V4。不要凭文档中出现的类名就断言代码存在。

按阶段自主实现、测试、修复、交付，不只再输出一份计划。第一个技术检查点是M0–M2；通过后继续M3–M6。阶段有外部阻塞时记录真实阻塞，继续能独立完成的工作。不得以几个基础fixture通过冒充全范围准备完成。

未授权：修改线上游戏状态、公开发布、GitHub push/PR、正式大规模数据生产、正式训练和多轮超参搜索、模型晋升、云资源付费、实时游戏连接。单元测试、合成契约测试、必要的受限工程smoke允许。用户再次明确授权时以其范围为准。

## 不可变用户要求

1. Silent，A10；只做战斗内决策；首版支持该角色单人合法涉及的卡牌/升级/敌人/遗物/药水及相关生成/状态机制。
2. 教师以公共信息条件期望评价到战斗与自动结算完成；未知真实seed、牌序和未来事件不进入任何玩家决策。
3. 药水整场保血9点是一般可考虑门槛，不强制立刻使用，保命例外；物品价值只计算一次。
4. 追求指定额外收益的整场增量期望战损<=5，下一玩家回合指定斩杀并获益概率>=0.8可接受，不是强制动作；仍需安全。
5. 允许安全有限地拖回合取收益；有限结束的合法无限可用；防够后停止无益防御循环，再作其他有益动作。
6. 当前60血且两种都赢、资源相同：90%无伤+10%掉30优于固定掉8；平均同为3时固定掉3优于前者。不要用过强风险项反转这些案例。
7. 不为速度牺牲明确更好的血量/安全/资源，不奖励无意义格挡、出牌次数或无限循环。

## 首先执行的审计

- 读取仓库AGENTS、README、实际代码与测试；登记checkout sha。参考基线为 `a3a66276ee79bf9f75e8af32e9ef5a51592b26f8`，不是强制升级指令。
- 核对SDK和构建命令，真实运行可运行的build/test。不能把本包的30项Python测试称为模拟器测试。
- 检查CombatState.Clone/RNG、CombatStateDescription、CombatRoom终局lifecycle、RunDriver决策与子选择。不能对clone调用原room造成污染。
- 检查已有公共观测、belief采样、教师、训练器是否真的存在；登记Verified/Partial/Blocked证据，不机械重写。
- 生成目标内容可达性与机制覆盖表。README声明的未实现项不得静默略过。
- 获取环境CPU/内存/磁盘/可用GPU事实，不凭用户的其他设备话题推断本任务配置。客户端版本未核对则标记未核对。

## 实现约束

所有规则仍委托原sim。新增层只负责公共观测、历史知识、合法动作封装、采样、分支生命周期、教师搜索及训练数据。确需补核心hook/clone能力，做局部最小扩展并加原版语义回归，不复制卡牌规则到Python。

精确clone不是belief采样。不能保留实际已物化隐藏牌序却声称重播种后已NOSL。当前公开intent、公开已知牌顶不能被采样抹掉。公开树中的策略不得访问完整world状态。

终点不得靠Engine.Won推测；必须验证自动回血、胜利hooks、pending效果、失败和清理。不得对共享room重复触发settlement。`generateRewards:false` 只有经过终点语义证明后才可作为局部优化。

对5点预算，不要发明“实际额外掉血”这样的可直接观测字段；它是反事实增量。追求收益要有公共锚点、固定截止、退出策略。模型输入不能依赖教师每步重新计算反事实值。未解决完整预算时间一致性前，应准确限制支持计划类型并记缺口。

主效用候选K=1000、eta=0.2仅供合成校准，不是用户确认常数。不得把 `calibrated=false` 改成true以绕过gate；生成校准证据，记录未确定范围。永久收益值、药水例外不得无证据赋值后声称最优。

独立标签评估样本应与搜索选优样本分开。轨迹截断/报错不得记作WIN或LOSS；采样账本计数守恒。不完整动作覆盖不得填零补齐。

部署只接公共快照、必要历史、合法候选及公开自身记忆；禁止依赖simulator或在线搜索。teacher version、label quality、seed、private digest等审计字段不输入网络。

## 测试与证据

先运行 `python -m unittest discover -s tests -v` 复验合成契约。把acceptance_catalog中的待实现检查逐项接入实际组件；记录命令、环境、输出和状态。不能把SPECIFIED_NOT_EXECUTED直接批量改成Passed。

每阶段至少交付：变更文件、实现摘要、实际测试、未通过项、支持范围、可复现命令。真实游戏对拍缺客户端或工具时必须Blocked，不使用mock冒充。

验收至少覆盖：隐藏替换；相同信息同策略；抽牌后合法分化；已知牌顶；子选择；clone独立；一次性终局结算；9/5/0.8边界；安全拖回合；无限展开等价；截断不误标；源战斗分组切分；独立推理。

## 交付与停止条件

输出 `NOSL_STATUS.md`、`TRAINING_READINESS.json`、基线锁、内容/机制manifest、适配与教师代码、训练/推理工程、测试和报告。ready字段必须由证据导出。

只完成受限闭环时为PILOT_READY。全范围尚缺规则、校准或必要证据时如实Blocked。READY_FOR_TRAINING不包含正式模型权重，也不等于首版模型验收通过。

完成授权目标后停止，不顺便做模组、UI、机器人集成、游戏外决策或云部署。
