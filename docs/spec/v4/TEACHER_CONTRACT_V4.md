# 教师、标签和偏好契约 V4

状态：可交给工程实现的设计＋局部可执行合成检查；尚非游戏教师实现。

## 1. 信息约束的精确定义

令 `I_t` 是当前公共局面、合法公开历史、已知约束，以及由玩家自己的公开行为维护的控制器记忆。令 `b_t=P(x_t | I_t)` 是未知状态的条件分布。

根动作a的教师评价为：从b_t采样假想world，先执行a，其后按冻结的可容许策略pi，仅依据当时I选择动作，运行到实际战斗终局。值为 `Q^pi(I,a)=E[U(Z_T)|I,a,pi]`。优化续策可以改善pi，但不可称有限搜索求得Q*的证明。

两个world在决策前仍有相同I时，后续策略的动作分布必须相同；观察到不同新手牌/事件以后才允许分化。不能在每个完整隐藏world中分别算最优再平均（策略融合）。

树节点按完整必要公共知识区分，不按屏幕当前值盲目合并；也不把隐藏state digest当节点key。精确隐藏hash可在分支内部做审计，但不能让策略复用带未来优势的结果。

## 2. 单条终局样本：先保存事实，再评分

`RolloutOutcome` 至少包含：

```text
terminal_kind: WIN | LOSS | COMPUTE_TRUNCATED | ENGINE_ERROR | POLICY_NONTERMINATING
player_alive, hp_at_combat_start, hp_after_settlement
max_hp_start, max_hp_after_settlement
cumulative_hp_damage, healing_received               # 诊断，不重复加分
inventory_start, inventory_end, consumed/generated  # 有来源追踪
permanent_changes                                   # 分类型，不先硬混成值
specified_finish_success, earned_bonus, deadline_met
player_turns_elapsed, atomic_actions_executed
settlement_profile_id, continuation_policy_id
```

`WIN`和`LOSS`遵循原游戏规则，不能凭“所有敌人血量<=0”自己判断；不把计算异常当死亡。

审计数据另存 `source_run_id / private_state_digest / exact_rng / sampler_seed / branch_id`，绝不进入学生输入。采样种子不是真实对局种子；训练审计的任何随机ID都不能暗中成为特征。

样本计数必须守恒：已分配world = 完成＋截断＋错误＋明确其他结果。不能丢弃长战斗后仅对容易完成的轨迹归一化。不同动作的完成率必须报告。

## 3. 终局主目标：候选实现而非新的用户命令

为了让风险可控、并避免每回合重算“最差10%”改变目标，本版建议使用固定终局效用的条件期望。CVaR/分位数保留为诊断与辅助标签，首版不直接拿动态重截尾的CVaR覆盖主排序。

每场战斗开始固定 `H_ref=max(1,H_start)`，途中不可改成当前HP。终局净战损为 `L=H_start-H_end`，允许负值（合法净回血）。

一个用于开发与校准的代价候选：

```text
C(Z) = K * 1[真实战斗失败]
       + L
       + eta * max(L,0)^2 / H_ref
       + V_inventory(start) - V_inventory(end)
       - V_permanent_future(Z)
Q(I,a) = - E[C(Z) | I,a,pi]                  # 越大越好
```

胜负惩罚作用于失败事件，不是将各种异常/未终局纳入失败。死亡也须作为单独事实概率报告。失败时不存在可保留的未来收益，终局资源估值按失去后续使用价值处理。正式资源表需有界、版本化，避免任意虚构奖金压过保命项。

本包合成检查使用 `K=1000, eta=0.2`，**只是待校准工程值**，不是用户已经确认的风险偏好，更不能解释成“死亡永远等于1000滴血”。正式label job读取 `calibrated=false` 必须拒绝作为正式档案运行；小型契约／校准实验可用。

不使用时间折扣，伤害／格挡／出牌次数不直接加奖励。先前的伤害与最终血量不重复计分；当前HP提升已进入H_end，不再同时作为永久加最大HP的即时收益重复奖励。永久收益项只估未被当场血量体现的未来部分。

不同物品和永久收益的价值还未被用户逐项定价。先保存原始向量，版本化定义估值，未校准内容标记 `objective_value_unresolved`。不为了填公式把全部永久收益设为0，也不自动承诺整局最优。

在无资源差异、都获胜、H_start=60的合成例子：

| 方案 | 候选期望代价 |
|---|---:|
| 固定掉8 | 8 + 0.2*64/60 ≈ 8.2133 |
| 90%无伤、10%掉30 | 3 + 0.2*90/60 = 3.3 |
| 固定掉3 | 3 + 0.2*9/60 = 3.03 |

它同时满足用户的两种取舍，但一个例子不能识别唯一风险模型。M3须做更多已确认边界的敏感性检查；对未确定的极小死亡风险取舍不能声称已获用户背书。

### 比较规则

先剔除非法/不支持的输入；不把这些动作计为“分数差”。真实不安全优先考虑，但不是声称任何万分之一死亡差异都压倒一切。主排序以校准后的同一效用目标进行，安全诊断只按有证据的规则介入，不能每个节点另换一套偏好。

没有可靠差异时返回近似等价集合/不确定性，不把噪声变唯一赢家。相同终局分布和资源价值时才用更少回合/动作作最后tie-break；对缺少差异证据不等于证明完全相同，避免用宽CI任意偏向速杀。

## 4. 9点药水规则

比较使用／保留同一瓶药水的完整可容许策略，不能只比较眼前效果。记录整场边际HP改善，同时记录风险、永久收益和其他资源变化。

9点是一般可用门槛；等于9也可进入候选；救命可以低于9。不能因为达标就强制现在喝。若双方最终都消耗同一瓶，主要比较时机，不能重复收取物品价值。

正式实现可把“资源清算价值”和“是否值得考虑的解释标签”分开。清算价值只入效用一次；9点门槛不再额外扣9。更高价值物品用显式例外表，不偷偷统一。

在采样估计跨越9的边界时，返回未决／补采样；不把估计9.01说成确定值得。置信区间规则须与采样停止方式兼容。

## 5. 5点和80%：有限期额外收益计划

### 5.1 基准的定义

在首次追求某项额外收益的公共锚点I0，定义 `pi_base`：不为这项收益额外拖延，但不禁止自然发生该收益的正常稳健策略。冻结其版本与目标，不使用明显弱基线虚增“追求收益很划算”的结果。

候选 `pi_bonus` 必须是依据公开观测分支的完整计划，包括失败后的退出/保命续策。比较：

`DeltaL = E[L(pi_bonus) - L(pi_base) | I0]`。

使用可比世界和独立策略执行估计差值，不读取真实牌序。共同随机数的具体耦合只是方差控制方案，不代表现实中同时存在两个可观察结果。

### 5.2 准入条件

对讨论中的指定斩杀：DeltaL <= 5；下一玩家回合结束之前，按指定方式完成斩杀、实际获得收益且自身未失败的**无条件**概率>=0.8；安全评价通过。

这里不是每条轨迹最多掉5，也不是全部战损至多5。80%不是“在已经活下来的分支中有80%”，失败、超时未拿到都不能从分母删除。

满足条件仅表明可考虑，仍与其他动作比较；微小永久收益不因为达标就必须追求。可安全拖多个回合回血的A8属于另一种有限收益计划，不滥用这个下一回合截止。

### 5.3 计划状态与部署不能偷带教师数值

`PublicControllerContext` 至少包含：公开锚点摘要、目标/已选行为、起始player turn、固定截止、active/aborted/finished、公开已发生事件。ID只作引用，不学习编号。

不能每个回合重开一份5点额度或移动截止。也不能把已观察到的总掉血直接称为“真实额外战损”：额外战损相对于反事实基准，不是可直接观测的量。

教师用同一锚点评估整个有限计划及后续修改，对风险／期望预算沿观察分支作可审计的条件预算管理；不能简单用每个节点独立Delta<=5拼接。实现没有此能力前，必须限制为明确的有限plan模板并验证，不宣称任意计划全支持。

学生只能接收由公共事件维护的上下文，不能要求调用方实时提供教师反事实值。学生可用网络头估计整体额外代价与成功概率；跨步骤约束的兑现要在纯学生闭环验收，**不能宣称神经网络具有数学保证**。不确定或过期时允许放弃，投入成本不构成继续冒险理由。

## 6. 教师采样、置信度与排序

对同一根信息I，每个独立world先由belief sampler生成，然后复制给各候选；未知未来与活局真实seed无关。每个分支执行同一冻结版本的可容许续策。所有非强制子选择也是玩家决策。

搜索用的自适应样本与最终标签评估分开：先确定候选策略，再使用预先固定或有有效序贯界的独立采样方案估计值。不要把反复观察普通95%区间后“刚显著就停”当作仍有95%保证。

阈值状态为 `ELIGIBLE_NOT_MANDATORY / INELIGIBLE / UNRESOLVED`。精确已知p=.8可准入；有限样本的区间跨.8时属于未决，不将“80%允许”误改为用户要求“真实概率必须显著大于80%”。

完成轨迹有界时，可用未完成概率质量乘以合法效用上下界给值界；若机制导致界未知，不能编造有限界。截断影响候选排序就不得生成强排名标签。工程预算不是游戏回合上限。

## 7. 数据分层：可推理输入、监督目标、审计元数据

```text
DecisionRecord
  public_input
    schema_version
    public_state
    public_history_summary / completeness
    public_knowledge_constraints
    public_controller_context
    candidate_actions / legal_mask
  targets
    action_result_moments / distribution
    value / pairwise_preference / equivalent_action_set
    specified_bonus_success / extra_expected_loss (where defined)
    result_quality / target_masks
  audit_only
    source_run_group, private_digest, sampler_seeds
    simulator_commit, rules_version, label_endpoint
    teacher_version, continuation_version, objective_version
    n_exploration, n_independent_eval, n_unresolved, n_error
```

审计字段不能整体拼入输入；标签质量、搜索排名和teacher confidence只能用于损失/审计。训练版本已知但部署不需要外部提供的目标profile可绑定模型包，不把ID当捷径特征。

所有候选保留独立估计；没有评价完就标未决，不能填0。终局HP、死亡和指定收益概率是不同头，0.9排序分不等于90%胜率。

## 8. 部署推理契约（拟新增）

输入包含公共局面、必要历史/知识、自己产生的公开控制器上下文、候选及其合法性。模型能校验结构，不能凭神经网络证明外部候选完整合法。

输出含动作对应的分数/结果预测、选中动作或近似等价集、适用性状态、明确原因。未知规则、缺失关键历史、空候选必须区分终局/等待/输入错误；不随机挑动作。

推理依赖闭包中禁止 simulator、教师、搜索器、真实seed、精确私有状态。允许静态规则词表和公共确定性前处理，但不能在其内部重建一个搜索教师。

## 9. 本包可执行检查的边界

`contracts/preference_contract.py` 只实现合成完整分布的候选终局代价、通用药水准入和额外收益区间准入；不实现真实规则、world采样、反事实预算续期、动作选择或神经网络。

`python -m unittest discover -s tests -v` 可复验30项局部检查。已执行结果保存在 `contract_test_report.txt`。完整待实现集成验收见 `acceptance_catalog.json`；不可将其写成已通过。
