## Important limits

This history file is sufficient for a structured **visited-route outcome dataset**,
but it is not a complete action replay:

1. It records one visited map-point sequence, not the full unvisited map graph or node coordinates/edges.
2. It records aggregate per-floor outcomes and `turns_taken`, not every card play, target, potion timing or enemy intent transition.
3. It records final deck/relic/potion state and per-floor changes, but not a full per-floor snapshot of every power/counter/RNG stream.
4. Shop/reward option IDs and aggregate spending are present, but exact shop prices and purchase order may need CLI logs or a live trace.
5. Event/Ancient choice IDs are present; full text/effects should be joined from the versioned localization/semantic catalog.

The extracted JSON and CSV are generated by `training/extract_run_history.py` and
keep the original source hash for provenance. The original `.run` file was not modified.
